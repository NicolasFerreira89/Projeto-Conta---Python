# Projeto Conta - Python 🏦

Este repositório contém o desenvolvimento de um sistema de **Conta Bancária** automatizado em Python. O projeto foi estruturado utilizando conceitos essenciais de **Programação Orientada a Objetos (POO)** para simular operações financeiras do mundo real de forma organizada e escalável.

## 🚀 Funcionalidades Esperadas

* **Criação de Contas:** Registro de contas bancárias com número, agência e titular.
* **Operações Financeiras:** Realização de depósitos e saques com validação de saldo.
* **Consulta de Extrato:** Exibição do histórico de transações e saldo atualizado.
* **Estrutura em POO:** Aplicação de conceitos como classes, atributos, métodos e encapsulamento.

## 🛠️ Tecnologias Utilizadas

* **Python 3.x**
* Paradigma de Programação Orientada a Objetos (POO)

## 📂 Estrutura do Repositório

O projeto está organizado da seguinte forma:

* `ProjetoConta/`: Diretório contendo os arquivos de código-fonte (`.py`), incluindo as classes de modelagem da conta e o fluxo principal de execução.

## 💻 Como Executar o Projeto

Se você deseja rodar a aplicação localmente, siga as instruções:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Entre na pasta do projeto:**
   ```bash
   cd Projeto-Conta---Python
   ```

3. **Execute o arquivo principal:**
   ```bash
   python main.py
   ```
   *(Ou substitua `main.py` pelo nome do arquivo principal que inicia o sistema dentro da pasta).*
